# App typography

Dashboard's ORE SCOUT wordmark uses the bundled **Pixelify Sans** variable face
at weight 700, with native outlines and silver/cyan shading. It is licensed under
SIL Open Font License 1.1; see `OFL.txt`. Other interface styles retain Monocraft.

The app uses **Monocraft** for its shared theme and text styles. Numeric input and ore coordinates use the regular face to keep digits clear. History uses the bundled bold face for seeds, versions and coordinates. The bold face also provides heading and label emphasis without synthesizing strokes.

- Project: https://github.com/IdreesInc/Monocraft
- Regular: https://raw.githubusercontent.com/IdreesInc/Monocraft/main/dist/Monocraft-ttf/Monocraft.ttf
- Bold: https://raw.githubusercontent.com/IdreesInc/Monocraft/main/dist/Monocraft-ttf/weights/Monocraft-Bold.ttf
- License: SIL Open Font License 1.1, included as `Monocraft-LICENSE.txt`.

Roboto remains the fallback for glyphs missing from Monocraft, including some Vietnamese characters. Its license is included as `Roboto-LICENSE.txt`.
